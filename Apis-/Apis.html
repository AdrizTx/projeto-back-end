APIs

O que é uma API?

API significa Application Programming Interface (Interface de Programação de Aplicações). Ela é
um conjunto de regras que permite que diferentes sistemas e aplicações se comuniquem. Por meio de uma API,
o Front-End pode enviar solicitações para o Back-End e receber informações ou pedir que alguma ação seja
realizada.

Para que serve uma API?

Uma API serve para facilitar a comunicação entre diferentes aplicações. Por exemplo, em uma loja virtual, o
Front-End pode utilizar uma API para buscar produtos, cadastrar clientes, realizar pedidos e consultar
informações do banco de dados. Dessa forma, o Front-End não precisa acessar diretamente o banco de
dados.

O que é API REST?

Uma API REST é uma API que segue os princípios da arquitetura REST (Representational State Transfer). Ela
utiliza principalmente os métodos HTTP, como GET, POST, PUT, PATCH e DELETE, para realizar operações
sobre recursos. Por exemplo, uma API pode utilizar /produtos para representar os produtos de um sistema.

O que são endpoints?

Endpoints são os endereços específicos disponibilizados por uma API para realizar determinadas operações.
Cada endpoint representa um recurso ou uma ação. Por exemplo, em uma API de produtos, podemos ter:

  • GET /produtos - lista os produtos.
  • GET /produtos/10 - busca o produto de número 10.
  • POST /produtos - cadastra um novo produto.

Como o Front-End utiliza uma API?

O Front-End utiliza uma API enviando requisições HTTP para os endpoints disponíveis. O Back-End recebe a
requisição, realiza o processamento necessário e devolve uma resposta, geralmente em formato JSON. O
Front-End então utiliza essas informações para atualizar e apresentar o conteúdo na tela para o usuário.


Método Função Exemplo de utilização
GET Buscar informações GET /produtos - para listar produtos
POST Criar novos dados POST /produtos - para cadastrar um produto
PUT Substituir/atualizar um recurso completo PUT /produtos/10 - para atualizar todos os dados do produto 10
PATCH Atualizar parcialmente um recurso PATCH /produtos/10 - para alterar apenas o preço do produto 10
DELETE Excluir um recurso DELETE /produtos/10 - para excluir o produto 10

Exemplos de utilização

GET: É utilizado quando o sistema precisa consultar informações. Por exemplo, ao abrir uma loja virtual, o
Front-End pode enviar GET /produtos para receber a lista de produtos disponíveis.

POST: É utilizado para criar uma nova informação. Por exemplo, ao preencher um formulário de cadastro, o
Front-End pode enviar POST /usuarios com os dados do novo usuário.

PUT: É utilizado para atualizar completamente um recurso existente. Por exemplo, ao editar todos os dados
de um produto, pode ser enviada uma requisição PUT /produtos/10.

PATCH: É utilizado para alterar apenas uma parte de um recurso. Por exemplo, se for necessário alterar
somente o preço de um produto, pode ser utilizada PATCH /produtos/10.

DELETE: É utilizado para remover uma informação. Por exemplo, quando um administrador exclui um
produto, o sistema pode enviar DELETE /produtos/10 para solicitar sua remoção.
