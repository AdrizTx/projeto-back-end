Funcionamento
do Back-End

Cliente e servidor?

O cliente é o dispositivo ou aplicativo que solicita algum serviço, como um navegador de internet.
O servidor é o computador responsável por receber essas solicitações, processar as informações e enviar
uma resposta ao cliente. Essa comunicação acontece constantemente quando acessamos sites e sistemas.

Requisição e resposta

A requisição é uma solicitação enviada pelo cliente ao servidor para realizar alguma ação, como acessar
uma página ou cadastrar um usuário. O servidor recebe essa requisição, realiza o processamento
necessário e envia uma resposta com o resultado da operação.

HTTP e HTTPS

HTTP é um protocolo utilizado para a comunicação entre cliente e servidor na internet. Já o HTTPS é uma versão
mais segura, pois utiliza criptografia para proteger os dados durante a comunicação. Por isso, o HTTPS é
muito utilizado em sites que trabalham com informações importantes, como senhas e dados pessoais.

Servidor Web

O servidor Web é responsável por receber requisições dos clientes e entregar os recursos solicitados.
Ele pode disponibilizar páginas, arquivos e também encaminhar requisições para aplicações de Back-End
que precisam realizar algum processamento.

Regras de negócio

As regras de negócio são as condições e procedimentos que determinam como um sistema deve funcionar.
Por exemplo, em uma loja virtual, uma regra pode determinar que um produto não pode ser comprado quando
não existe estoque disponível.

Validação de dados

A validação verifica se os dados enviados pelo usuário estão corretos e dentro das regras estabelecidas pelo
sistema. Por exemplo, o Back-End pode verificar se um e-mail possui um formato válido ou se determinados campos
obrigatórios foram preenchidos.

Processamento no servidor

O processamento no servidor acontece quando o Back-End recebe os dados, executa as operações necessárias e
pode consultar ou alterar informações em um banco de dados. Depois disso, o servidor envia o resultado de volta
para o cliente, permitindo que o sistema apresente as informações ao usuário.

Funcionamento da Comunicação entre Usuário, Front-End e Back-End

Quando um usuário realiza uma ação em um site, como clicar em um botão ou enviar um formulário, o
Front-End identifica essa ação e envia uma requisição para o servidor. Essa requisição geralmente utiliza o
protocolo HTTP ou HTTPS e contém as informações necessárias para realizar a operação.

Ao receber a requisição, o Back-End processa os dados, verifica as regras de negócio e realiza as validações
necessárias. Se for preciso, ele também consulta ou altera informações no banco de dados. Depois de
concluir o processamento, o servidor prepara uma resposta com o resultado da solicitação.

Por fim, a resposta é enviada de volta ao navegador, que recebe os dados e atualiza a página para mostrar o
resultado ao usuário. Dessa forma, o processo pode ser resumido como: usuário → Front-End → requisição
→ servidor/Back-End → processamento → resposta → Front-End → usuário.
